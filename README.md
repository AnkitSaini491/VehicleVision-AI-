# 🚗 VehicleVision AI

VehicleVision AI is a real-time vehicle detection and traffic analysis system built using Python, YOLO, and OpenCV.

## Features

- 🚗 Car Detection
- 🏍️ Motorcycle Detection
- 🚌 Bus Detection
- 🚚 Truck Detection
- 🟩 Green Bounding Boxes
- 🎯 Confidence Scores
- 🔢 Vehicle Counting
- 📊 Live Detection HUD
- 🎥 Video Analysis
- 🤖 YOLO AI Object Detection

## Technologies

- Python
- YOLO
- Ultralytics
- OpenCV
- Computer Vision
